# Сайт ООО «Альбектус»

Статический сайт без фреймворков и зависимостей: HTML + CSS + немного JS, сборка скриптом на Python 3 (только стандартная библиотека).

## Где что менять

| Что | Файл |
|---|---|
| ИНН, ОГРН, адрес, e-mail, телефон, адрес сайта, свой домен | `site.config.json` |
| Тексты главной страницы | `src/index.html` |
| Политика конфиденциальности / согласие | `src/privacy.html`, `src/consent.html` |
| Шапка и подвал | `src/partials/header.html`, `src/partials/footer.html` |
| Стили (цвета — в начале файла) | `src/assets/style.css` |
| Title / description страниц | `build.py`, словарь `PAGES` |

Пустое поле в `site.config.json` выводится на сайте как «уточняется». Пока `email` пустой, кнопка формы неактивна.

## Сборка и просмотр

```
python3 build.py --local
python3 -m http.server -d dist 8000   # http://localhost:8000
```

## Публикация

Хостинг — GitHub Pages. При каждом изменении в ветке `main` GitHub Actions (`.github/workflows/pages.yml`) собирает сайт и публикует его. Реквизиты можно править прямо в веб-интерфейсе GitHub: открыть `site.config.json` → карандаш → Commit — через 1–2 минуты сайт обновится.

## Свой домен

1. В `site.config.json` указать `"custom_domain": "example.ru"` (без https://).
2. У регистратора домена добавить DNS-записи:
   - для `example.ru` — четыре A-записи: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`;
   - для `www.example.ru` — CNAME на `<логин>.github.io`.
3. В репозитории: Settings → Pages → Custom domain → ввести домен → Save, после проверки DNS включить «Enforce HTTPS».

## Форма обратной связи

Сервера нет: форма формирует письмо в почтовой программе посетителя (`mailto:`). Данные на сайте не сохраняются — это отражено в политике конфиденциальности. Если понадобится приём заявок без почтового клиента, нужен внешний сервис форм; политику тогда нужно дополнить.
